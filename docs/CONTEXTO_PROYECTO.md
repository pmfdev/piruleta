# Contexto del Proyecto

## Nombre

- Piruleta Kid

## Objetivo general

- Construir un juego para el sobrino del propietario del repositorio.

## Situacion actual

- Repositorio inicializado con documentacion base y commits en `develop`.
- Rama activa: `develop`.
- Planificacion funcional del juego completada.

## Alcance inicial

- Definir vision del juego.
- Definir plan por fases.
- Definir arquitectura tecnica minima.
- Implementar una primera version jugable (MVP).

## Definicion actual de producto

- Edad del jugador: 11 anos.
- Plataforma objetivo: Android.
- Tipo de juego: exploracion 3D en Marte.
- Protagonista: rover tipo NASA.
- Modo de juego v1: campana lineal de 3 misiones.
- Duracion maxima de partida: 7 minutos.
- Controles: joystick virtual y un boton de accion.
- Referencias de gusto: Minecraft, espacio y construccion tipo Lego.
- Idioma de interfaz: espanol.
- Interfaz: paneles e iconos para informacion y configuracion.
- Requisito de conectividad: juego offline.
- Publicacion objetivo: APK para compartir y opcion de tienda Android.
- Stack tecnico: JavaScript + Three.js + Capacitor.
- Relieve de mapa: no homogeneo (colinas/montanas suaves y rocas).
- Estaciones de recarga: 3 distribuidas en el mapa.
