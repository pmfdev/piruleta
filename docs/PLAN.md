# Plan de Trabajo

## Fase 0 - Descubrimiento

- Confirmar perfil del jugador (edad e intereses).
- Elegir plataforma y tecnologia.
- Elegir tipo de juego.

## Fase 1 - Diseno del nucleo jugable

- Definir mecanica principal.
- Definir reglas de ganar/perder.
- Definir ciclo de partida.

## Fase 2 - MVP tecnico

- Crear estructura base del proyecto.
- Implementar escena principal.
- Implementar controles.
- Implementar sistema de puntos/vidas/estado.
- Implementar pantalla de inicio y fin.

## Fase 3 - Contenido y experiencia infantil

- Arte base (placeholders o sprites iniciales).
- Sonidos y musica suave.
- Ajuste de dificultad y ritmo.

## Fase 4 - Pruebas y pulido

- Corregir bugs.
- Revisar rendimiento.
- Prueba real con el jugador.
- Ajustes finales.

## Fase 5 - Entrega

- Publicar version jugable.
- Documentar mejoras para v2.

## Registro de avance

- 2026-02-17: Se crea base documental del proyecto.
