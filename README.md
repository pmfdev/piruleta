## Resumen del juego (v1)

- Jugador: nino de 11 anos.
- Plataforma objetivo: Android.
- Formato: juego 3D en Marte.
- Personaje principal: rover inspirado en NASA.
- Duracion maximo de partida (campana v1): 7 minutos.
- Controles: joystick virtual + 1 boton de accion.
- Idioma: espanol.
- UX: iconos/paneles para informacion y configuracion.
- Requisito offline: si.
- Distribucion objetivo: APK compartible y publicacion en tienda Android.
